# Limbus Company

> A turn-based mobile game by Project Moon, set in a dark and strange world.

## About

**Limbus Company** is a mobile RPG made by *Project Moon*, a South Korean studio. It is set in the same universe as *Lobotomy Corporation* and *Library of Ruina*. The story is inspired by classic literature, like Dante's *Divine Comedy*.

## Story

You play as the **Manager**, who leads a group of 12 people called **Sinners**. Together, they travel through different "Cantos" to collect Golden Boughs for the Limbus Company.

## Some Fave Sinners

1. Meursault
2. Don Quixote
3. Ryoshu
4. Yi Sang
5. Hong Lu
6. Heathcliff

## Gameplay Features

- Turn-based combat
- Coin-flip skill clashes
- Collect and upgrade Identities
- Story-driven chapters
